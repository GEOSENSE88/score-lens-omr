전체 흐름 한눈에 보기

업로드 후에는 화면의 STEP 1 → 5 순서 그대로 진행됩니다. 판독(③)까지는 전부 자동입니다.

OMR Lens는 스캔한 답안지 PDF에서 수험번호·성명·선택과목·답안(수학 단답형 포함)을 자동으로 읽어 채점하고, 반·번호 기준으로 과목을 합쳐 통합성적표(엑셀)를 만들어 줍니다. 선생님이 하실 일은 스캔 → 업로드 → 확인 필요 학생만 검토 → 채점 버튼이 전부입니다.

➋

스캔 준비 — 이것만 지켜 주세요

권장 설정: 컬러 · 300dpi · 과목별 PDF. 이 세 가지면 충분합니다.
항목권장이유
색상컬러 (필수)카드의 빨간 인쇄를 지우고 연필 마킹만 남기는 방식이라, 흑백 스캔은 정확도가 크게 떨어집니다. 흑백으로 올리면 화면에 "컬러 재스캔 권장" 표시가 뜹니다.
해상도300dpi복합기 기본값이면 대부분 그대로 사용 가능합니다.
파일과목별 PDF반이 섞여 있어도 되고, 순서도 상관없습니다. 스캐너가 나눠 저장한 여러 PDF를 한 과목에 모두 첨부해도 됩니다.
방향자유거꾸로·옆으로 스캔돼도 자동으로 돌려서 읽습니다. 살짝 비뚤어진 것도 자동 보정됩니다.
💡 백지(결시) 카드가 섞여 있어도 괜찮습니다. 아무것도 마킹되지 않은 카드는 자동으로 명단에서 제외됩니다.

STEP 1 — 시험 정보 선택

  1. 학년(고1·고2·고3)을 먼저 누르세요. 학년에 맞는 시험 목록과 과목 카드가 나타납니다.
  2. 시험을 고르세요. 시험 종류(학력평가·모의평가)에 맞는 답안지 양식이 자동으로 선택되고, 선택창 아래에 어떤 카드 양식으로 읽는지 표시됩니다.
  3. 목록에 원하는 시험이 없으면 아래의 "EBSi에서 정답 가져오기"로 연도·월을 골라 정답을 자동 등록할 수 있습니다.
  4. 성명 명단 CSV(선택)를 첨부하면 판독한 성명과 명단을 대조해서, 다르게 읽힌 학생에게 자동으로 표시를 달아 줍니다. 없으면 카드에 마킹된 성명을 그대로 사용합니다.

STEP 2 — 답안지 업로드

과목 카드를 클릭해서 PDF를 고르거나, 파일을 카드 위로 끌어다 놓으세요. 한 과목에 여러 PDF를 첨부할 수 있고(자동으로 합쳐서 판독), 파일 오른쪽 ✕ 로 뺄 수 있습니다. 올리고 싶은 과목만 올리면 됩니다 — 전 과목이 아니어도 채점됩니다.

⚠️ 과목 카드와 실제 PDF 과목이 맞는지 한 번만 확인해 주세요. 수학 답안지를 국어 카드에 올리면 판독 결과가 온통 "확인 필요"로 표시됩니다.

준비가 끝나면 [답안지 스캔 시작]을 누르세요. 과목별 진행률이 실시간으로 표시되고, 끝난 과목부터 바로 검토할 수 있습니다.

3

STEP 3 — 판독 결과 검토·수정

① 판독 상태 읽는 법

학생 목록의 "판독 상태" 칸을 보면 어디를 확인해야 하는지 알 수 있습니다.

화면 예시 — 판독 상태 표시
정상 전 문항이 깨끗하게 판독됨 — 확인 불필요
미마킹 2 · 중복 1 빈 문항·이중 마킹이 있음 — 답안을 열어 실제로 안 푼 것인지 확인
⚠ 수험번호불완전 자동 판독이 확신하지 못한 학생 — 카드 보기로 원본을 대조해 직접 수정

② 카드 보기 — 스캔 원본과 대조

모든 학생 행에 버튼이 있습니다. 누르면 그 학생의 실제 답안지 스캔 이미지가 뜨고, 이미지를 클릭하면 확대됩니다. 원본을 보면서 바로 옆의 반·번호·성명 칸을 고치면 됩니다. ⚠ 표시가 있는 학생은 버튼이 처럼 강조되어 있으니 이 학생들부터 확인하세요.

③ 답안 보기·수정

[답안 보기·수정]을 누르면 문항별 그리드가 펼쳐집니다. 색으로 정오가 표시되고, 셀을 누르면 바로 고칠 수 있습니다. 수정하면 즉시 재채점됩니다.

STEP 4·5 — 채점과 통합성적표

검토를 마쳤으면 [채점하기]를 누르세요. 반·번호 기준으로 과목이 합쳐지고 과목별 평균·분포 요약과 함께 다운로드 파일이 만들어집니다. 채점 후에도 답안을 수정하면 결과에 다시 반영됩니다.

파일내용
통합성적표.xlsx반·번호·성명별 전 과목 원점수와 예상 등급, 대교협·UNIV 양식 시트, 예상등급컷 근거 시트
과목별 점수표과목별 문항 답안·틀린문항·미마킹·중복마킹 상세
정오표학생별 문항 정오를 한 장으로 — 배부용
⚠️ 표준점수·백분위·등급은 EBSi 예상 등급컷 기반 추정치이며 공식 성적표를 대체하지 않습니다. 고3 국어·수학은 원점수 컷이 공개되지 않아 예상치가 제공되지 않습니다.
🔒 업로드한 답안지 PDF는 채점 직후 서버에서 삭제되고, 결과 파일도 통합성적표를 내려받는 즉시(또는 일정 시간 후 자동으로) 완전히 삭제됩니다.

이런 표시가 뜨면 — 문제 해결

표시뜻대처
⚠ 정렬실패페이지가 접히거나 겹쳐 스캔되는 등 카드 위치를 잡지 못함카드 보기로 원본을 확인하세요. 카드가 훼손됐으면 그 장만 다시 스캔해 올리면 됩니다(기존 파일에 추가 첨부 가능).
⚠ 수험번호불완전수험번호 마킹이 비었거나 흐림카드 보기로 원본을 대조해 반·번호 칸에 직접 입력하세요.
⚠ 성명판독불가 / 성명대조불일치성명 마킹이 불완전하거나 명단 CSV와 다름카드 보기로 확인 후 성명 칸을 고치세요.
⚠ 흑백 스캔 감지컬러가 아닌 스캔 — 판독 신뢰도 낮음스캐너를 컬러로 바꿔 다시 스캔해 올리는 것을 권장합니다.
미마킹 다수실제로 안 풀었거나, 마킹이 매우 연함답안 그리드를 열어 카드 보기와 대조 — 연한 마킹이면 해당 문항만 직접 입력하세요.
답안 그리드가 비어 보임그 시험의 정답이 아직 등록되지 않음STEP 1에서 "EBSi에서 정답 가져오기"로 정답을 등록한 뒤 다시 채점하세요.
